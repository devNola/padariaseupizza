**Esse repositório contém a Web para a Padaria Seu Pizza, para o projeto de desenvolvimento I, Contendo uma aplicação focada no front-end em Html Puro com js e css.**

```
Clonando o Repositorio
```

# Clonar o projeto 
```
git clone git@gitlab.com:senac-projetos-de-desenvolvimento/2024-arthur-sabino-granvilla-da-silva-e-filipe-siega-barbosa/front_client.git
```
# Entrar na pasta do projeto
```
cd padariaseupizza-web
````

# Instalação das dependencias necessárias
```
npm install e npm install -g serve
```

# Executando a aplicação web
```
npm run dev
```

**Após iniciar a aplicação web, voce pode acessar o endpoint da tela de inicio e navegar pelo site. Basta abrir esse link http://localhost:3000 no seu navegador.**
